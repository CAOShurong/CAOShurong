## Shurong Cao

I build small command-line tools that answer one question well, and refuse to
answer when the data can't support it.

They share the same constraints: **zero runtime dependencies**, standard
library only, tested on Linux, Windows and macOS across Python 3.9–3.13, and
documentation whose figures are generated by running the tool, so CI fails when
they drift.

### What they have in common

Each one exists because the honest answer to a common question was *"nobody
checks that"*.

Every eval framework runs your test cases; none ask whether the test cases are
any good. Every API-diff tool tells you what a library changed; none tell you
whether you used any of it. `-X importtime` tells you what is slow to import;
it does not tell you what you could move into a function.

So the hard part is usually not the measurement — it is knowing when the
measurement does not license a conclusion, and saying so instead of printing a
confident number.

- `evalint` refuses to call an eval item broken on three systems, because three
  systems genuinely cannot tell a broken item from an unlucky one. It reports
  the p-value it could not clear rather than a threshold it invented.
- `willitbreak` will not report a call site whose origin it cannot prove
  statically. It under-reports on purpose, because it is meant to be a required
  CI check.
- `jsonxray` counts *absent* and *explicitly null* separately, and quotes every
  percentage against its own parent rather than the file, because the other way
  invents data-quality problems that aren't there.
- `contextcost` prints its error bound next to every total, because it
  estimates tokens rather than tokenizing them, and that bound is measured
  against a real tokenizer in CI rather than asserted.
- `runproof` treats a check that *could not run* as a failure rather than a
  skip. Treating "could not verify" as "fine" would reintroduce, in one line,
  the exact hole the tool exists to close.

A tool that cries wolf gets uninstalled after the second false alarm, and then
catches nothing at all.
